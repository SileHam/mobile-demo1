# mobile-demo1

Introductory React Native and Expo coursework demonstration.

## Local use

Install the locked dependencies with `npm ci`, then run `npm start`.
Use Expo Go on a compatible device. Device behavior was not tested during this upload.

## Additional JavaScript exercises

The `examples/` folder preserves standalone hello-world and article-array exercises from the local coursework folders. These scripts can be run separately with Node.js.
